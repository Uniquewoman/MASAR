# خطة المحتوى التعليمي — مسار

المرجع المعتمد لتوزيع المواضيع على المستويات. **أي سؤال يُضاف للداتابيس لازم يتبع هذي الخطة.**

## القواعد

| القاعدة | القيمة |
|---|---|
| مستويات كل قسم | ٥ |
| بنك الأسئلة لكل مستوى | **٩٠** سؤال (هدف مرحلي، يُرفع لاحقاً) |
| يُسحب في المحاولة | ٣٦ = ٣٠ صحيحة + ٦ أخطاء |
| العبور | ٣٠ إجابة **صحيحة** |
| الفشل | ٦ أخطاء |
| عدم التكرار | لا يتكرر سؤال حتى تنتهي أسئلة المستوى، ثم تبدأ دورة جديدة مخلوطة |

### مبدأ ترتيب المواضيع
- كل مستوى ياخذ **٢–٣ مواضيع مترابطة**
- **ما يتكرر موضوع** بين مستويين — كل موضوع له مكان واحد
- **ما ينحط موضوع قبل متطلبه**
- L5 دائماً أصعب مواضيع القسم

### توزيع أنواع الأسئلة — يتدرّج مع المستوى

المستوى الأول أغلبه اختياري وسهل، وكل ما ارتفع المستوى **تزيد الأكواد والماتش والصح‑وخطأ** ويقل الاختياري. من أصل ٩٠ سؤال:

| النوع | L1 | L2 | L3 | L4 | L5 |
|---|---|---|---|---|---|
| اختيار من متعدد | ٦٠ | ٥٢ | ٤٥ | ٣٨ | **٣٠** |
| كود | ١٠ | ١٥ | ٢٠ | ٢٥ | **٣٢** |
| صح وخطأ | ٨ | ٨ | ٨ | ٩ | **١٠** |
| سيناريو | ٥ | ٦ | ٦ | ٦ | ٦ |
| تيرمنال | ٤ | ٦ | ٧ | ٨ | ٨ |
| ماتش | ٣ | ٣ | ٤ | ٤ | ٤ |

### تدرّج الصعوبة داخل المستوى

| المستوى | `easy` | `medium` | `hard` |
|---|---|---|---|
| L1 | ٥٠٪ | ٤٠٪ | ١٠٪ |
| L2 | ٣٥٪ | ٤٥٪ | ٢٠٪ |
| L3 | ٢٥٪ | ٥٠٪ | ٢٥٪ |
| L4 | ١٥٪ | ٥٠٪ | ٣٥٪ |
| L5 | ١٠٪ | ٤٥٪ | **٤٥٪** |

> ملاحظة تقنية: الأسئلة تُخلط عشوائياً بالكامل عند كل محاولة (Fisher‑Yates)، ثم تُوزَّع بحيث لا يتجمّع نفس الموضوع أو النوع في أسئلة متتالية. لا تعتمدي على `question_order` لترتيب العرض — هو للأرشفة فقط.

### نموذج مكتمل يُحتذى: البرمجة / أساسيات / L1

٩٠ سؤالاً فريداً بلا تكرار، موضوعان فقط (التعليقات والمتغيرات):

| النوع | العدد | | الصعوبة | العدد |
|---|---|---|---|---|
| اختيار من متعدد | ٥٣ | | سهل | ٤٠ |
| كود | ١٤ | | متوسط | ٣٨ |
| صح وخطأ | ٧ | | صعب | ١٢ |
| ماتش · تيرمنال · متعدد · ترتيب | ٤ لكل نوع | | | |

### معايير جودة السؤال
- واقعي من ممارسة فعلية، مو حفظ نظري
- **الخيارات الخاطئة معقولة** — أخطاء يقع فيها المبتدئ فعلاً، لا حشو واضح
- ملتزم بموضوع مستواه، ما يخرج عنه
- غير مكرر مع أي سؤال موجود
